Shared `Localizable.strings` remain in the source root.
- Apporo signature is `APPORO UNION INC.`; no claim of transferred copyright. All three display names are `Apporo platform`.
- `asset-manifest.json` records the read-only mark input and output hashes. `generate_apporo_assets.py` composites onto opaque white without cropping/resizing. The UI still follows system/user dark mode; white applies only to mark assets. iOS has no separate primary dark/light palette: fixed/default colors use `#8B6B24`, on-primary white, and existing `WoowTheme.scheme(for:)` handles saved user colors.
